# Contributing to Online_Examination_System

Keep contributions focused, testable, and easy to review.

## Workflow
1. Create a focused branch.
2. Reproduce the issue or define the expected behavior.
3. Make one coherent change at a time.
4. Run the project's available checks before committing.
5. Use a clear commit message.

## Quality
- Never commit secrets or local environment files.
- Avoid unrelated refactors in fixes.
- Update documentation when setup or behavior changes.
- Include reproduction and verification details for bug fixes.

## Pull requests
Describe what changed, why it changed, how it was tested, and any known limitations.
